THE CORE IDEA

One input. Two different interpretations.

SQL injection happens when untrusted text is combined with executable query syntax. Binding parameters makes the database treat each value as data.

UNSAFE PATTERN · SIMULATED ONLY01

Concatenation blurs the boundary

When input is embedded into query text, SQL punctuation may be parsed as part of the command. The isolated lab demonstrates this only with fictional records.

query = SQL_TEMPLATE + user_input
# isolated training database only

PROTECTED · LIVE SQLITE02

Parameters preserve the boundary

SQLite receives a fixed query and its values separately. The sample login also checks a salted password hash before creating a session.

SELECT id, username, password_hash
FROM lab_users WHERE username = ?
